# agents/

One folder per agent. Copy _template, or just say "make me an agent for <job>" (skill: make-agent).

Each agent keeps every run in three places: input/ (what it was asked), wiki/ (what it thought and did), output/ (what came out). RUNS.md lists every run in one line.

Autonomy ladder: every agent starts at level 0, proposals only. Level 1 (tidy actions) after about two weeks of clean runs, level 2 (routine actions end to end) after a clean month more. Only the owner promotes an agent. No level may message people, spend money, delete data or edit the rules.
