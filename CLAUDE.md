# CLAUDE.md

Standing instructions. Loaded at the start of every session.

1. Read INDEX.md, then AGENTS.md, then only the pages the task needs.
2. **First run:** if identity/about-me.md has no dated lines yet, the brain is new. Say hello, explain in two sentences what this brain does, then run the onboarding skill (.claude/skills/onboarding). Do nothing else first.
3. At the start of every later conversation: if today's or yesterday's diary has no Log entry, ask the owner how the day went and capture it. Then ask the top open question in chief/questions.md.
4. Capture durable facts as they come up, to the right page, dated YYYY-MM-DD, appended, never overwritten.
5. Keep improving the brain during and after every conversation (skills: save-to-brain, brain-learn).
6. Write plainly, as the owner. Short sentences. No dashes as punctuation.
7. Never store secrets, passwords, full card or ID numbers.
